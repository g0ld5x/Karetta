# Karetta


>**"Programs must be written for people to read, and only incidentally for machines to execute." — Harold Abelson**

## What is karetta?
Karetta is a compiled and interpreted programming language that aims to find a middle ground between high-level languages like Python and Lua and lower-level languages like C and C++.

## Why karetta?
Karetta focuses on the developer experience. Alongside ahead-of-time (AOT) compilation, it provides an interpreter for quick prototyping and experimentation. This lets you iterate on ideas without waiting for a full compilation, so you can focus less on the mechanics of writing and building code and more on actually creating your program.
